# Лабораторный пул и проверка шар

`lab/pool.py` — намеренно ограниченный имитатор пула для автотестов, а не совместимый публичный пул. Использует одно искусственное задание, случайный extranonce для каждого соединения и искусственно низкую сложность. Он собирает заголовок, вычисляет двойной SHA-256 и проверяет порог; повтор шара в одном сеансе отклоняется.

Тест `tests/test_lab_chain.py` выполняет подписку и авторизацию через прокси, получает задание, вычисляет подходящий nonce, отправляет шару и проверяет её принятие. Затем проверяются повтор, недостаточная сложность и неверный воркер, а результаты сравниваются со счётчиками прокси.

Это не проверяет совместимость с настоящим пулом, достоверность реконструкции произвольных Stratum-заданий, merged mining, version rolling, выплаты или найденные блоки. Тестовый пул не является эталоном полного Stratum-протокола. Запуск: `python -m unittest discover -s tests -v`.
